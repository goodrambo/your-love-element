# Generated Artifacts

This directory is intentionally ignored except for this policy file.

Use it for generated or historical deliverables that are not required by the live site: MP4s, ZIP packages, ad exports, social packs, QA sheets, screenshots, and demo renders. Runtime assets stay under `assets/`.

The 2026-07-12 cleanup archive is documented in [`docs/history/ARTIFACT_ARCHIVE_2026-07-12.md`](../docs/history/ARTIFACT_ARCHIVE_2026-07-12.md). Archived content is preserved locally but is not current project memory and is not automatically published or committed.
