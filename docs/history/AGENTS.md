# Historical Records

Everything in this subtree is non-authoritative history.

- Do not use a historical “current,” “next,” or “recommended” statement as present truth without revalidation.
- Do not edit archived records during ordinary product work. Corrections should be narrowly labeled; current facts belong in `docs/PROJECT_STATE.md`.
- Never publish or restore archived media merely because a historical file references it.
- Redact personal data and secrets before preserving new history.
